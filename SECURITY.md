# Security Policy

## Supported versions

There are no releases: only the latest commit of the `main` branch receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue.
Use [private vulnerability reporting](https://github.com/iRingil/adobe-reaper/security/advisories/new) instead.

Include the commit you built from, steps to reproduce, and the potential impact.
This is a solo-maintained project; reports are handled on a best-effort basis.
